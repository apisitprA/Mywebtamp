# Monitor & Analysis

เปิด Dashboard จาก start_pi_dashboard.bat แล้วกด Ctrl+F5 ไปที่แท็บ **แนวโน้มการทำงาน** จะพบชุดกราฟ Monitor & Analysis ด้านบน

เลือกชุดกราฟได้ดังนี้:
- Setpoint ทั้ง 8 จุด: Turbo Vacuum และวาล์วกระบวนการทั้ง 7 จุด
- SP เทียบ Actual พร้อม % Valve: เลือกดูทีละจุด โดยแรงดันและวาล์วแยกแกนตามหน่วย
- กำลังไฟ / รอบมอเตอร์ / อัตราผลิต / พลังงานจำเพาะ
- การผลิต / ความเร็วเดินกระดาษ / Basis Weight / Jet-Wire Ratio / ไอน้ำ
- คุณภาพ: Dryness Soft Sensor / Moisture Size Press / Basis Weight
- อุณหภูมิแบริ่งและมอเตอร์ 5 จุด
- แรงดันไอน้ำ Dryer 10 จุด

ทุกชุดใช้ช่วงเวลาเดียวกัน มีกราฟ RUN/BREAK และแสดงเกรด ณ เวลาที่ชี้กราฟ เส้นประคือ SP เส้นทึบคือค่าจริง กดชื่อสัญญาณเพื่อซ่อนหรือแสดงเส้น กราฟรวม % วาล์วทั้ง 8 จุดยังอยู่ถัดลงไป

**ขยายช่วงบนกราฟ:** กดเมาส์ค้างแล้วลากจากเวลาเริ่มถึงเวลาสิ้นสุด ปล่อยเมาส์เพื่อซูมและอ่านข้อมูล PI ของช่วงนั้นใหม่ ระบบปรับความละเอียดตามช่วงที่เลือก กราฟและตารางสถิติในชุด Monitor จะเปลี่ยนช่วงพร้อมกัน ส่วนกราฟวาล์วรวมซูมแยกได้

ดับเบิลคลิกบนกราฟเพื่อซูมเข้า 2 เท่ารอบเวลาที่กด หรือใช้ปุ่ม **ซูมเข้า 2×** เพื่อขยายช่วงกึ่งกลาง ปุ่ม **ย้อนกลับ** กลับไปหนึ่งขั้น และ **คืนช่วงเดิม** กลับก่อนเริ่มซูม กด Esc ขณะลากเพื่อยกเลิก ซูมได้ถึงช่วง 1 นาที (จุดประวัติละเอียดสุด 1 นาที) การซูมปิดโหมดติดตามล่าสุดเพื่อให้ช่วงวิเคราะห์คงที่ การเลือกชุดกราฟหรือโหลดช่วงใหม่จะเริ่มประวัติการซูมใหม่

เลือกย้อนหลัง 1 ชั่วโมง, 6 ชั่วโมง, 24 ชั่วโมง, 7 วัน, 30 วัน, 2 ปี หรือกำหนดวันเวลาเอง แล้วกด **แสดงกราฟ** ปุ่ม **ถึงเวลาปัจจุบัน** จะเลื่อนช่วงมาถึงเวลาล่าสุด ช่อง **ติดตามล่าสุด** อ่านประวัติใหม่ทุก 30 วินาทีเฉพาะเมื่อเปิดแท็บนี้ ส่วนค่าปัจจุบันบนหน้าภาพรวมยังอัปเดตทุก 1 วินาทีตามเดิม

ตารางด้านล่างมีค่าล่าสุดในช่วง / ต่ำสุด / สูงสุด / เฉลี่ย / จำนวนข้อมูลที่ใช้ได้ และส่งออกทุกสัญญาณในชุดที่เลือกเป็น CSV ได้ เวลาใน CSV เป็น ISO พร้อมเขตเวลา ส่วนหน้าจอใช้เขตเวลาของเครื่องผู้ใช้

ประวัติอ่านจาก PI Archive โดยลดความถี่ของจุดข้อมูลเมื่อเลือกช่วงยาว (อย่างน้อย 1 นาที ไม่เกินประมาณ 2,001 จุดต่อเส้น) จึงไม่ใช่ข้อมูลทุกเหตุการณ์ และค่าสถิติคำนวณจากจุดที่แสดง อาจไม่เห็นเหตุการณ์สั้นกว่าความละเอียดนั้น ข้อมูลไม่ดี/ขาดหายแสดงเป็นช่องว่าง ไม่แทนด้วย 0

เลือกย้อนหลัง 2 ปีได้ แต่แต่ละแท็กมีประวัติยาวไม่เท่ากัน โดยเฉพาะ SP และ Dryness อาจไม่มีข้อมูลช่วงต้น ไม่มีการสร้างข้อมูลแทนส่วนที่ขาด

Specific Energy = kW ÷ t/h ใช้เฉพาะจุดเวลาที่ตรงกันและอัตราผลิตมากกว่า 0 ค่า Turbo SP และ Suction Blower Vacuum แสดงชื่อจุดวัดแยกชัดเจน ไม่ถือว่าเป็นเซนเซอร์ตำแหน่งเดียวกัน
