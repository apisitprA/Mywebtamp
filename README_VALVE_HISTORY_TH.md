# กราฟประวัติระดับเปิดวาล์ว

เปิด Dashboard → แนวโน้มการทำงาน → ระดับการเปิดวาล์ว · ทุกจุด

- รวม Suction Box, Couch Roll, Pick-up High/Low, 1st/2nd/3rd Press Felt และ Diffuser Guide Vanes ในกราฟเดียว
- แสดงค่า MV ของ PI หน่วย % บนแกนคงที่ 0–100
- เลือก 1 ชั่วโมง, 6 ชั่วโมง, 24 ชั่วโมง, 7 วัน, 30 วัน, 2 ปี หรือกำหนดวัน–เวลาเอง
- คลิกชื่อวาล์วเพื่อซ่อน/แสดงเส้น; ชี้กราฟเพื่อดูค่าทุกจุด
- ข้อมูล Bad/Questionable/ไม่ใช่ตัวเลข/นอก 0–100 แสดงเป็นช่องว่าง
- จุดข้อมูลเป็นค่าตามเวลาที่สุ่มจาก PI Archive ไม่ใช่ค่าสูงสุด/ต่ำสุดในช่วงนั้น; ช่วงยาวลดความถี่ให้ไม่เกิน 2,001 จุดต่อเส้น เช่น 2 ปีแสดงทุก 12 ชั่วโมง
- กด “ถึงเวลาปัจจุบัน” เพื่อเลื่อนช่วงมาที่เวลาล่าสุด; กราฟย้อนหลังไม่ดึงซ้ำทุกวินาที

เมื่อติดตั้งบนเครื่องอื่น ให้ปิด Dashboard Server เดิมแล้วเปิด start_pi_dashboard.bat ใหม่ จากนั้นกด Ctrl+F5 เพื่อโหลด API /api/valve-history และไฟล์กราฟใหม่
